# TimetoDate

一班人夾時間的網頁：開一個活動，派一條連結出去，每個人入名填自己有空的日子與時段，頁面即時計出熱力圖與最多人有空的時段。

**網址**：https://junoching.github.io/TimetoDate/

## 使用方法

1. **建立活動**：輸入活動名稱、日期範圍（最長 31 日）、每日時段，並設定 4 至 6 位數字的刪除 PIN。
2. **分享連結**：進入活動頁後按「複製活動連結」，把連結傳給朋友。
3. **填寫時間**：朋友開啟連結，輸入名字，先在月曆點選有空的日子（長按已選日子可取消），再逐日填寫時段（每格 30 分鐘，有「全日」一鍵全選與「複製此日時間至其他日子」）。
4. **查看結果**：活動頁有「已參加」名單（可點按人名查看其填寫的時間）、月曆熱力圖（按每日單一時段的最多重疊人數計算），點按日子與時段可查看誰有空、誰未選該時段。
5. **刪除活動**：活動頁右上方「刪除活動」，輸入建立時的 PIN 即可刪除（連同所有回覆）。

同一名字再次開啟連結並載入，即可修改自己的回覆。

## 技術

- 前端：單一 `index.html`（原生 HTML/CSS/JS，無建置步驟），由 GitHub Pages 託管。
- 後端：Supabase（Postgres + REST API）。活動與回覆存於資料庫，所有訪客讀寫同一份資料。
- PIN 只以雜湊形式存於獨立資料表，公開 API 無法讀取；建立與刪除活動經資料庫函數驗證。後端設定見 `supabase-schema.sql`。
